## 你得到什么（固定边界）

| # | 交付 | 验收标准 |
|---|------|----------|
| 1 | 只读余额 | 查余额类 tool **立即返回**；审计记 `ALLOWED_READ` |
| 2 | 动钱提议闸 | 转账/付款类 tool **只签发** `confirmToken`（TTL≤10 分钟），**不改** Demo 余额 |
| 3 | 人确认后落地 | 消费有效 token 后才改沙箱账本；无效/过期 → `DENIED` |
| 4 | 金额限额 | 软阈值提示 + 硬限额直接拒绝（token 不可绕过；限额数字可按你方改） |
| 5 | 审计日志 | JSONL：who / tool / 金额摘要 / decision / 时间；可导出查阅 |
| 6 | 联调讲解 | 30–45 分钟：查余额 → PENDING → APPROVED / DENIED（含超硬限额） |

技术栈口径：Java · Spring Boot · Spring AI（含 `@Tool(requiresConfirmation)` 与 MCP `confirmToken` 双路径叙事）。
